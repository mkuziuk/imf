EMD, linear IMF and IRMF: component count, pimf 0.5.0 and robustness

How many components?

Each method was rerun with K extracted components plus one residual, on the same 15 grouped splits as the main study. For IMF and IRMF, K is the number of stages of a recursive IMF that covers the same range of scales as the default 17 (15 on synthetic), so fewer stages means wider spacing between them. For EMD, K is the number of IMFs kept, and everything coarser stays in the residue. The comparison at equal counts was pre-registered before any of these models were fit.

Equal component counts

Paired differences in balanced-accuracy points, fixed classical model, features without log_scale. Bold cells passed Holm correction across all 48 tests. The pre-registered reading counts a dataset as keeping the IMF advantage if both IMF methods beat EMD significantly at K = 5 and K = 6.

pimf's default k_max = 8

pimf extracts the coarsest stages first. With k_max = 8 it stops early, and every finer stage ends up lumped into the residual. The chart compares that cut-off with all stages of the recursive IMF, and pimf's full defaults (60-step gradient descent with k_max = 8) with EMD's default.

Switching to pimf 0.5.0 and 0.5.1

pimf 0.5.0 adds IMF(..., solver="newton"), and gradient descent now warns when a stage hits its iteration cap. pimf 0.5.1 makes that Newton solver faster without changing its results. Each release was rerun on every frame of the four datasets, in its own environment. 0.5.0 is compared with the 0.4.0 results the experiments used, and 0.5.1 with 0.5.0.
