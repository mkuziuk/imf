Classification study, Laplace follow-up

Robustness to Laplace noise: EMD, linear IMF and IRMF

Design

Each sample independently receives Laplace noise with probability p. The scale is one robust SD of its clean raw channel, 1.4826 times the MAD, with standard-deviation fallback. Constant channels receive no noise. The levels are clean, 10%, 20%, 30% and 40%. There is no Gaussian term or Gaussian control. Methods share the same noise draws, and contamination masks are nested across levels. Noise enters before the shared median/MAD normalization.

The impulse run's prepared datasets, four inputs, 15 grouped splits and 100 excluded pilot frames per dataset are unchanged. The shared 20 features come from float32 component stacks. Fixed classical models are linear SVM for DroneRF and ESC-50, and logistic regression for BirdCLEF and synthetic. LightGBM settings are unchanged. All model scaling and selection use training rows only. Clean features are checked on 50 frames per dataset before contaminated features are computed.

All four datasets share one pool of 14 workers, with one native thread per worker. Feature chunks run first, then fits in descending expected cost. Matched classical training covers 40% contamination only. IRMF uses our safeguarded Numba Newton solver, with tolerance 10⁻¹², a 100-step cap and a retry at 1,000 steps. It recomputes H from each contaminated channel.

The pre-specified reading at 40%

The main measure is the change in the IRMF − linear IMF balanced-accuracy gap from clean to contaminated test data, paired over the same 15 grouped splits. Positive DiD means linear IMF lost more than IRMF. IRMF counts as more robust if the 40% primary DiD is positive with Holm p < 0.05. A negative significant DiD favors linear IMF. A non-significant result establishes neither direction.

Balanced accuracy vs contamination share

Models train on clean data and predict the same held-out fold at every level. Curves show mean balanced accuracy. Each panel has one y axis; its range includes chance at 1 / classes.

How the gaps change

DiD(p) = [BA IRMF(p) − BA comparator(p)] − [BA IRMF(clean) − BA comparator(clean)]. Values are percentage points. Positive values mean the comparator lost more accuracy. Read these relative effects alongside the absolute curves.

Tests use two-sided Nadeau-Bengio corrected t-tests. Whiskers are marginal 95% corrected intervals. Filled markers and bold cells use Holm p < 0.05. Intervals are not simultaneous, so an interval may exclude zero while the Holm test is not significant.
