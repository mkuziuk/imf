The BirdCLEF wrapper imports `baselines/run_classical.py` and calls its `run` function with `quick=False`, all four main methods, and all six classifiers. It replaces the fold worker to cache native probabilities and completed fits, and narrows only the SVM C grid. It uses three joblib workers, one BLAS/OpenMP thread each, and grouped inner three-fold CV. Temporary feature memmaps also go under DATA_ROOT. Cached fits can resume a run; use fresh `results/classical_phase2/narrow/<task>` and `full/<task>` directories to repeat computation from scratch. Linear SVM uses the shared deterministic primal solver choice; its shared estimator has no native probability output.

Reported grids: QDA shrinkage `auto, .05, .2, .5, .8`; logistic C `.001, .01, .1, 1, 10`; kNN k `1, 5, 15, 35`; linear SVM C `.001, .01`. LDA uses automatic Ledoit-Wolf shrinkage and Gaussian NB uses shared defaults. No feature selection uses all-frame discriminability. All 15 outer folds are retained; `--quick` was never used.

Runtime reduction: a species full-grid pilot was interrupted after roughly ten minutes. Completed EMD SVM fits took 67-157 seconds each, projecting over an hour for the first task once both feature sets and the larger IMF feature matrices were included. The decision used this partial first-task pilot rather than waiting for a complete species run. Only SVM C `.1, 1` were dropped, identically for every method and both tasks. Completed identical non-SVM pilot fits were reused; full-grid pilot SVM fits are excluded from every reported analysis. Pilot caches and logs are retained under DATA_ROOT for audit. Thus this is full repeated CV with a reduced SVM tuning grid, not a completed original-grid study.

`all_classifier_metrics.csv` and `best_classifier_metrics.csv` contain balanced accuracy, macro-F1, and accuracy, each with outer-fold SD. The best classifier is selected using the 15 outer-fold mean and is descriptive. The compact paired verdict uses logistic regression, specified before decomposition classification results were inspected. No test treats the best-of-six choice as prespecified.

`paired_all_metrics.csv` contains all six method pairs, both feature sets, all six classifiers, and all three metrics. Nadeau-Bengio variance is `(1/15 + mean(n_test/n_train)) * sample_variance(differences)`, with Student t confidence intervals and 14 degrees of freedom. Holm covers 72 comparisons within each task-by-metric table, spanning both feature sets and classifiers. Wilcoxon is secondary. `paired_logreg_balanced_accuracy.csv` retains this same conservative 72-comparison correction. All 1,152 per-species recall comparisons form one additional Holm family. The log-scale ablation has 24 comparisons per task and metric.

`scale_discriminability_<task>.csv` averages and takes medians/maxima of epsilon-squared and Miller-Madow-corrected 16-bin MI over each component's 20 features. Epsilon-squared is `H/(N-1)`, matching the shared runner. These are descriptive statistics on all frames; frame dependence prevents interpreting Kruskal-Wallis p-values as independent-frame evidence. Fine-to-coarse order comes from `emdirmf.decompose.scale_order`, including the finest pimf residual first. Observed spectral centroid median and 10th/90th percentiles in Hz exclude zero-padded components. `fs/window` is only a nominal smoothing scale, never a measured passband. EMD and IRMF have adaptive/nonlinear components. This table does not equate similarly numbered slots across methods.

`recording_results_folds.csv` averages native class probabilities over every recording's held-out selected frames, separately for each seed and fold. This pools the prepared short frames, not the entire recording. A recording never crosses folds, because the split unit remains recordist. All five probabilistic classifiers are included. `recording_logreg_metrics.csv` gives a common-classifier comparison with the same fold mean used for frame scores; `recording_results_pooled_seeds.csv` also scores all 1,280 recordings together within each seed. The underlying per-recording probability caches stay under DATA_ROOT. There is no majority vote, cross-seed probability averaging, calibration on test data, or looser recording-grouped refit.

`convergence_subset_metrics.csv` gives all classifiers/methods within the same IRMF-defined converged/unconverged subsets. These models still train on the full training fold. `convergence_species_composition.csv` documents label and level differences. Some unconverged species test subsets have 15 rather than 16 classes; subset balanced accuracy follows the shared metric's present-class convention. The report therefore also gives ordinary accuracy and does not interpret the subsets as matched populations. Differences are observational and do not estimate the causal effect of additional solver iterations. No higher-iteration IRMF ablation was run.

`decomposition_costs.csv` reports CPU seconds per frame from the completed decomposition caches, plus original wall times and failures. Original decomposition sessions used different worker counts, so compare CPU/frame rather than session wall time. Raw has zero decomposition cost; normalization and feature extraction are separate costs. EMD has 180 component features, linear IMF and IRMF have 360, and raw has 20; each receives the same additional log-scale feature in the amplitude ablation. Feature dimension is therefore a possible confound in comparisons with EMD/raw.

One wrapper cache bug was found and repaired before analysis. Pandas string labels were initially saved as an object array. A minimal reproduction is `np.savez(path, y_true=np.array(['barswa'], dtype=object))`, then `np.load(path, allow_pickle=False)['y_true']`, which raises `ValueError: Object arrays cannot be loaded when allow_pickle=False`. The wrapper now converts labels to NumPy Unicode before saving. Only this session's existing caches were migrated to that representation, preserving fitted predictions/probabilities; all analysis loads use `allow_pickle=False`. No shared-code numerical bug was observed.
