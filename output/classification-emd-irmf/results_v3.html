What changed from the Laplace run

The earlier pipeline reached 5-sample windows, put the spike scale below the robust threshold, and fixed the component counts. This run stops linear IMF and IRMF at 31 samples. Finer content stays in the residual. It scales spikes from the channel's own clean noise estimate and compares each method at its best clean K.

Each sample receives a signed-exponential spike with probability p, at 10%, 20%, 30% or 40%. Clean is p = 0. The rule is x + 1[u < p] · b · e · s, where e is unit exponential, s is a random sign, and b = 3σ̂ of the clean raw channel. σ̂ = median|diff(x)| / (0.6745√2). There is no Gaussian term. A constant channel receives no noise. Common draws give nested masks and the same positions as the Laplace run. Injection precedes median/MAD normalization.

The scale b is 1.5 times the channel's own clean threshold 2σ̂, as in the earlier notebooks. The amendment fixes the actual IRMF threshold H per dataset using the 100 excluded clean pilot frames. H is twice the median E1 estimate across their normalized channels. It never changes with p, frame or K. Those frames enter no classifier. The IQR pilot retained E1: 8 of 12 lower-error cells and 4 of 12 no-worse-stability cells fell short of the required 9 and 7. Thus b / fixed H varies by channel and normalization.

H values are in normalized units. Window lists below run from coarse to fine. Real frames have L = 2048; synthetic has L = 1024.

All linear IMF and IRMF window lists

EMD uses K ∈ {2, 3, 4, 6, 8}. One PyEMD run extracts 8 IMFs plus residue per channel. Lower K keeps the first K IMFs and folds the rest into the residue. Linear IMF and IRMF use K ∈ {3, 4, 6, 8, 11} on real data, and {3, 4, 6, 8, 9} on synthetic. Each stack has K components plus its residual.

The same 20 features per slot use float32 decomposition stacks. Raw features use float64 normalized samples, as corrected in the amendment. No log_scale features are used. The 5 grouped folds × 3 seeds are unchanged. Classical models are linear SVM on DroneRF and ESC-50, and logistic regression on BirdCLEF and synthetic. Model scaling and C selection use training rows only.

IRMF uses converged safeguarded Newton roots, tolerance 10⁻¹², a 100-step cap and a 1,000-step retry. The amendment governs fixed H and float64 raw features.

Each method gets its best clean K

K* maximizes mean clean balanced accuracy over the 15 outer splits, with ties going to smaller K. Each dataset, classifier and method selects its own K*. That K stays fixed at every contamination rate and in matched fits. Clean outer-fold selection makes these clean scores slightly optimistic. K selection is descriptive and is not nested.

Each cell gives K* and clean balanced accuracy. Raw has no K. EMD selects the bottom grid value K2 on DroneRF and BirdCLEF with classical models, and on DroneRF with LightGBM. A smaller K might be better still. The grid cannot answer that.

The pre-specified reading at 40%

DiD is the change in the IRMF − comparator balanced-accuracy gap from clean to contaminated data. Positive DiD means the comparator lost more accuracy. The primary reading favors IRMF if the 40% classical DiD vs linear IMF is positive with Holm p < 0.05. A negative significant value favors linear IMF. Otherwise, the test does not reject; not equivalence.

These tiles use classical K*. DroneRF's positive primary result is a floor effect. Its 40% scores are near 10% chance. A smaller loss does not imply useful classification.

How the gaps change at K*

DiD(p) = [BA IRMF*(p) − BA comparator*(p)] − [BA IRMF*(clean) − BA comparator*(clean)]. Values are pp. Read relative losses alongside the absolute scores above.

Two-sided Nadeau-Bengio corrected t-tests use 15 paired splits. Whiskers are marginal 95% corrected intervals. Filled markers and bold values use p_nb_holm < 0.05. Intervals are not simultaneous. An interval can exclude zero while the Holm test does not reject; not equivalence. Wilcoxon is secondary and is retained in the source CSV.
